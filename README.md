# ENGVERO - Free Online English Learning Platform

Explore the free learning modules available on ENGVERO:

- **[English Grammar Guide](https://engvero.netlify.app/grammar/)** — Clear rules, real-world examples, and common pitfalls.
  - [Articles (A, An, The)](https://engvero.netlify.app/grammar/articles-a-an-the/)
  - [Prepositions (In, On, At)](https://engvero.netlify.app/grammar/prepositions-in-on-at/)
- **[All 12 English Tenses](https://engvero.netlify.app/tenses/)** — Formula cards, signal words, and usage rules.
  - [Present Simple](https://engvero.netlify.app/tenses/present-simple/)
  - [Present Continuous](https://engvero.netlify.app/tenses/present-continuous/)
  - [Present Perfect](https://engvero.netlify.app/tenses/present-perfect/)
  - [Past Simple](https://engvero.netlify.app/tenses/past-simple/)
  - [Future Simple](https://engvero.netlify.app/tenses/future-simple/)
- **[Common English Mistakes](https://engvero.netlify.app/common-mistakes/)** — Quick fixes for confusing word pairs.
  - [Say vs Tell](https://engvero.netlify.app/common-mistakes/say-vs-tell/)
  - [Speak vs Talk](https://engvero.netlify.app/common-mistakes/speak-vs-talk/)
  - [Look vs See](https://engvero.netlify.app/common-mistakes/look-vs-see/)
  - [House vs Home](https://engvero.netlify.app/common-mistakes/house-vs-home/)

- **[Interactive Quizzes](https://engvero.netlify.app/quizzes/)** — Instant-feedback tests for grammar and tenses.
- **[English Level Test](https://engvero.netlify.app/english-level-test/)** — Free CEFR (A1–C1) placement assessment.
- **[Gemini AI Chat Tutor](https://engvero.netlify.app/chat/)** — Interactive English practice with conversational AI.
